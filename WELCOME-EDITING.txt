宏國地政|易丞地政：三帳號歡迎訊息修改說明

目前歡迎文字由 Webhook 程式發送，後面先接「服務導覽」首卡，再接原「買賣與房貸」「傳承、土地與交屋」兩頁。
服務導覽依各帳號既有啟用設定顯示，包含交易、貸款備件與官方六項服務，並能返回原六大需求卡。
LINE Official Account Manager 的原生「歡迎訊息」保持關閉，避免重複發送。
在 LINE 後台修改原生歡迎訊息，不會修改這份程式版文案。

方式一（最省事）：把「帳號 ID＋新文案」傳給本對話，協助修改、檢查及發布。

方式二（自行修改）：
1. 開啟 https://github.com/homegoestate/nexus-line-bot/blob/main/welcome-messages.json
2. 以有編輯權限的 GitHub 帳號登入，按編輯按鈕。
3. 找到 @604gpqef（品牌官方）、@528scwxf（楊代書個人）、@375umdzq（建案中心）。
4. 只修改該帳號 paragraphs 內引號中的文字。每個字串是一段，段落間會自動空行。
5. 保留帳號 ID、括號、逗號、version 與 label 等結構。字串內換行請寫 \n，雙引號寫 \"。
6. 修改 main 分支並提交後會觸發正式部署，並非僅儲存草稿。若先討論，請不要直接提交 main。
7. 到 https://vercel.com/homego/nexus-line-bot 確認該次提交已 READY，再測試歡迎訊息。

限制與注意：
- 每帳號最多 8 段、每段最多 400 字元、合計最多 900 字元；建議維持約 300 字元，避免過長。
- 保留統一品牌「宏國地政|易丞地政」。
- 不支援把 {Nickname} 當作暱稱替換；本版用「您好」，不額外抓取客戶個資。
- 不要填 API 密鑰、客戶個資、未核實承諾或尚未提供的功能。
- 若 JSON 損壞或不合格式，程式會回到通用歡迎文字；這不代表新版文案已正確發布。
- 原有六大需求卡、關鍵字回覆、新屋主登錄網址與 Webhook 不要一併修改。
- 官方／官方服務入口仍由 LINE 後台原生回覆；程式六項服務順序為 A 買賣過戶、B 貸款規劃、C 收支比試算、D 法人簽約、E 自然人簽約、F 加入社群。
- A「買賣過戶」直接開啟 hgchat:v2:process 的完整交易八階段；後台圖文 A 可使用既有文字「服務導覽：交易流程」，不可改接「買賣」或「交易流程」。
- B～F 仍交原生回覆：B 個人送「貸款」、官方與建案送「貸款規定」；C「收支比」、D「公司簽約」、E「簽約」、F「申請加入 宏國地政 | 易丞地政 VIP社群」。不要新增同關鍵字 webhook 回覆。
- 群組／多人聊天室只支援公開「服務導覽」、既有「服務導覽：」精確文字與 hgchat:v2 公開資訊卡回呼；A 同樣顯示交易八階段。回覆會顯示給聊天室成員。
